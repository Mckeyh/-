## 五、注意事项与待确认

1. `app.json` 使用 `navigationStyle: "custom"`，页面没有原生标题栏，也没看到页面注册 `navigation-bar` 组件 → 本次用页面顶部内边距规避（`.page-wrap` 的 `padding-top`）。
   **建议**：要么把 `navigationStyle` 改回默认（自带标题栏，最省事），要么在每页注册并放置 `navigation-bar` 组件。
2. `renderer: "skyline"` + `componentFramework: "glass-easel"`：本次样式只使用 flex、圆角、阴影、渐变等安全属性，避免 CSS 变量与复杂定位，降低渲染差异风险。
3. 图片上传仍是 base64 走 JSON（分类/训练），大图容易超时；建议后端支持 multipart，或前端加 `wx.compressImage` 压缩。
4. 小程序目前**没有鉴权**；后端如启用 Token，需在请求头统一加 `X-API-Token`。
5. 拍照图片复制到 `USER_DATA_PATH` 后**未清理**，长期使用会占用存储，建议补清理逻辑。

**渲染器选择说明**：原工程使用 `skyline` + `glass-easel`。skyline 对 CSS 的支持有限（部分属性不生效、必须在 `scroll-view` 内滚动、模拟器与真机表现差异较大），而本工程未使用任何 skyline 专属组件，因此**改用默认 webview 渲染器**：兼容性最好，真机与模拟器一致，样式按标准 CSS 生效。

> ⚠️ 待确认：后端目前输出的识别结果是**病害类别**（如番茄晚疫病）。前端标题已按"害虫防治识别"调整，若正式主题为害虫，需要后端更换数据集（建议 IP102 害虫数据集）重新训练，否则会出现"标题写害虫、结果是病害"的不一致。
